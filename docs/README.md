# QNEST documentation

`QNEST_User_Guide.html` is the main user guide and is opened by the Documentation button in the desktop application.

`QNEST_AI_Assistant.md` describes assistant setup, live context, validated actions and result access.

`QNEST_Knowledge_Base.md` is the local factual reference supplied to the assistant for QNEST-specific questions.

Bug reports are prepared for **elyasi@chalmers.se** from the Report a Bug dialog.
